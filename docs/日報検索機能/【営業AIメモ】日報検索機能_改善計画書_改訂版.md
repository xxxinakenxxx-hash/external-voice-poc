# 【営業AIメモ】日報検索機能 改善計画書

作成日：2026年7月27日  
対象画面：個人日報 S-05／管理職向け日報まとめ S-06  
状態：計画確定・未実装

---

## 1. 目的

個人日報および管理職向け日報まとめで、過去の商談記録を条件指定して検索できるようにする。

現在は次の固定表示となっている。

- 個人日報：直近30日分
- 管理職向け日報まとめ：当日0時から現在時刻まで

本改善では、既存の日報画面・既存データ・既存権限を維持したまま、期間、担当者、顧客名／店舗名、案件テーマ、商談内容、ToDo、追記内容による検索を追加する。

---

## 2. 改善後の検索条件

### 2.1 個人日報

対象は、現在の権限で閲覧できる本人の記録に限定する。

- 期間
  - 今日
  - 前日
  - 過去7日
  - 過去30日
  - 開始日・終了日指定
- 顧客名／店舗名
- 案件テーマ
- 商談内容
- ToDo
- 追記内容
- 上記を対象としたキーワード部分一致

初期表示は、現在どおり直近30日とする。

### 2.2 管理職向け日報まとめ

対象は、現在の閲覧権限の範囲内に限定する。

- 期間
  - 今日
  - 前日
  - 過去7日
  - 過去30日
  - 開始日・終了日指定
- 担当者
- 顧客名／店舗名
- 案件テーマ
- 商談内容
- 追記内容
- 上記を対象としたキーワード部分一致

初期表示は、現在どおり当日分とする。

---

## 3. 権限制御

検索機能を追加しても、現在の閲覧範囲は変更しない。

| ロール | 検索対象 |
|---|---|
| sales | 本人の記録のみ |
| manager | 同じ営業所の担当者の記録 |
| sales_support | 現在許可されている閲覧範囲 |
| sysadmin | 全記録 |

検索条件を指定しても、権限外の記録はサーバー側で除外する。

HTML側だけで制御せず、GAS側の検索処理でも必ず権限判定を行う。

---

## 4. 処理方式

新しい画面や外部APIは作らず、既存の個人日報・日報まとめを拡張する。

1. 日報画面上部に検索欄を追加する。
2. 検索条件を同じGAS Webアプリへ送る。
3. GAS側で入力値と日付を検証する。
4. ロールと閲覧範囲を先に確定する。
5. 期間、担当者、キーワードで商談記録を絞り込む。
6. 対象レコードの追記を取得する。
7. 追記内容を含めて最終的なキーワード判定を行う。
8. 新しい順で画面へ表示する。

## 12. 全工程共通の停止条件

次の場合は独断で処理を広げず、その地点で停止して報告する。

- DB・列・シートの追加が必要になった
- 現在のロール定義を変更する必要が生じた
- 現在の閲覧権限を変更する必要が生じた
- 新しい外部APIやパッケージが必要になった
- 指定した期間のデータ量でGASの実行時間制限に達した
- 正本文書と現行実装の権限定義が一致しない
- 指定外ファイルの変更が必要になった
- 既存URLやデプロイ構成の変更が必要になった
- 検索対象に `original_text`、メールアドレス、`user_key` が必要になった
- 既存の追記機能を壊さずに実装できない
- 前工程の完了条件を満たしていない
